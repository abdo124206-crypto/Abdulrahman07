# Firebase setup

1. Create a Firebase project.
2. Add a Web App.
3. Copy the Web App config into `firebase.js`.
4. Enable:
   - Firestore Database
   - Authentication → Email/Password
5. Create Admin and Driver users in Firebase Authentication.
6. Add the custom claims/roles later when the backend is finalized.

Collections used by the app:
- `orders`
- `menu`
- `drivers`
