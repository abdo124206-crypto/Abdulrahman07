# AL PRINCE FOOD — Customer Website

واجهة عميل Responsive لمطعم مشويات وأكل شرقي.

## التشغيل
افتح `index.html` مباشرة، أو شغله باستخدام Live Server.

## GitHub Pages
ارفع المشروع كما هو إلى GitHub، ثم فعّل GitHub Pages من Settings → Pages.

## الصور
كل الصور المستخدمة داخل:
`assets/images/`

تم فصل الصور من صور المنيو المرسلة، لذلك الموقع لا يعتمد على روابط صور خارجية.

## مهم
نسخة الـCustomer الحالية Prototype Frontend:
- Menu + search + category filters
- Cart
- LocalStorage للسلة
- Checkout UI
- Responsive / Mobile-first

الخطوة التالية في المشروع الكامل:
1. Backend + Database
2. Admin Dashboard
3. Delivery Dashboard
4. ربط الطلبات لحظيًا بين الواجهات الثلاث.
